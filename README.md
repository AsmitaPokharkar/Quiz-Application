# Quiz-Application

A beginner-friendly Quiz Application developed using HTML, CSS, and JavaScript , made as a Sem 2  mini project. This project helps users test their knowledge through interactive quizzes with multiple categories, timer functionality, score tracking, leaderboard system, and night mode support.

Features :
1. User Login System
2. Multiple Quiz Categories
3. Random Question Selection
4. Timer for Each Question
5. Real-time Score Tracking
6. Progress Bar
7. Leaderboard using Local Storage
8. Restart Quiz Option
9. Night Mode Toggle
10. Responsive and Attractive UI
    
🛠️ Technologies Used :
HTML5
CSS3
JavaScript (Vanilla JS)

💡 About the Project :
This project was created as a beginner-level web development project for Semester 2 in Computer Science Engineering. The main goal of this project was to understand the basics of frontend development and JavaScript programming concepts.

While building this project, I learned:
DOM Manipulation
Event Handling
Arrays and Objects in JavaScript
Functions and Timers
Local Storage
UI Design using CSS
Interactive Web Application Development

📸 Functionalities Implemented :
✅ Login System
Users can enter their username before starting the quiz.
✅ Quiz Categories
Users can select different categories for attempting quizzes.
✅ Timer System
Each question has a countdown timer of 30 seconds.
✅ Leaderboard
Scores are stored using browser local storage and displayed in leaderboard format.
✅ Night Mode
A night mode feature is added for better user experience.
